# Welcome to my blog

欢迎来到我的小站！我是一名正在学习中探索的学生，闲来无事捣鼓了这个博客。
日常会更新一些课程笔记、阅读心得，以及作为异乡人的生活记录。

目前正在学习：

- 计算机相关课程

## 关于本站

本站主要是我个人的笔记仓库和记录空间，按不同身份分为几个篇章：

- **as_student** — 课程学习笔记
- **as_staff** — 工作经验与思考
- **as_reader** — 阅读笔记与心得
- **as_foreigner** — 异乡见闻与感悟

内容或有不足，还请多多包涵。感谢每一位来到这里的访客！
